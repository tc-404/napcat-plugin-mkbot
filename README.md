## 简介

**MKbot** 是面向 QQ 的综合型机器人插件，运行在 **NapCat** 或 **咔咔珂（Kakake / MKcc 兼容层）** 之上。它把群管理、授权计费、娱乐经济、媒体解析、表情合成、智能对话、发卡商城等能力收拢到同一套指令与 WebUI 里，适合长期挂机的娱乐群与需要轻度运营的管理群。

核心特点：

- **双宿主**：NapCat 原生插件 + Kakake（`loader: MKcc`）兼容
- **事件驱动群管**：按群独立开关 24 项群事件（含表情制作、图片鉴黄）+ 5 项全局事件
- **本地授权 / 卡密**：按群或私聊授权，也可一键「绕过授权」自用
- **娱乐经济**：货币「归笺」体系 + 签到 / 钓鱼 / 银行 / 轮盘 / 商店 / 禁言卡等
- **分项娱乐开关**：每个功能可按群 / 好友单独开关
- **双渲染后端**：HTML（依赖 Puppeteer 插件）或 Sharp 本地出图
- **完整 WebUI**：基础 / 进阶 / 开关 / 智能对话 / 发卡 / 数据修改等
- **纯中文指令与界面**（部分表情指令有英文别名）

机器人内可随时发送：

| 指令 | 作用 |
|------|------|
| `菜单` / `/MK` | 主菜单 |
| `MK介绍` | 含演示对话的完整模块说明 |
| `群管系统` / `群管菜单` | 群管指令速查 |
| `事件管理` | 查看 / 开关事件 |
| `授权系统` | 授权与卡密菜单 |
| `插件配置` / `运行状态` | 运行参数与状态 |

## 安装部署

### 方式一：使用已构建产物

1. 获取发布包（或自行 `npm run build`），得到目录 **`napcat-plugin-mkbot/`**。
2. 将整个文件夹放入宿主插件目录，例如 NapCat：

```text
…/napcat/plugins/napcat-plugin-mkbot/
```

Linux 常见路径示例：

```text
插件目录：
/root/Napcat/opt/QQ/resources/app/app_launcher/napcat/plugins/

数据目录（新版本 NapCat 常迁移到）：
/root/Napcat/opt/QQ/resources/app/app_launcher/napcat/config/plugins/napcat-plugin-mkbot/
```

3. 重启 / 重载插件。
4. （可选）安装 Puppeteer 渲染插件，以便使用 HTML 卡片。
5. 打开 WebUI 或编辑 `config.json`，至少配置 **主人 QQ（OwnerQQs）**。

### 方式二：从源码构建后部署

见下方 [从源码构建](#从源码构建)。构建产物目录即为 `napcat-plugin-mkbot/`，复制到插件目录即可。

### Kakake 注意

- `plugin.json` 中插件名为 `kakake-plugin-mkbot`，加载器为 `MKcc`。
- 数据 / 插件路径可能与纯 NapCat 命名不同，迁移时请对照宿主文档，避免装错目录。

## 快速上手

推荐首次配置顺序：

1. **设置主人**  
   NapCat 配置面板或 WebUI「基础设置」填写 `OwnerQQs`（多个 QQ 用逗号分隔）。

2. **放行会话**  
   在 WebUI「开关管理」把目标群加入 `group_of`、好友加入 `haoyou_of`（也可后续用指令切换群聊 / 私聊消息执行）。

3. **授权或绕过**  
   - 自用：`config.json` 开启 **`绕过授权`**  
   - 正式：主人生成卡密 → 群内 `使用卡密…`，或 `添加月卡授权` 等

4. **打开需要的事件**  
   发送 `事件管理`，例如：`开启入群欢迎`、`开启违禁检测`。

5. **打开娱乐分项**  
   WebUI 娱乐开关，或兼容旧指令 `开启深度娱乐`（分项未配置时回退总开关）。

6. **日常玩法示例**  
   `签到` → `钓鱼` → `商店` / `买#诱饵 #1` → `幸运轮盘30` → `存款100`

未授权时机器人可能回复：`MK没能量啦～要充电电～～`

## 授权系统

模块：`src/auth/card-license.ts`  
数据目录：`筱筱吖/授权系统/授权信息/`

面向「按群 / 私聊计费运营」场景；自用不想折腾可在配置中开启 **绕过授权**。

### 主要指令

| 指令 | 说明 |
|------|------|
| `授权系统` | 完整授权菜单（合并转发） |
| `授权判断` / `授权判断[群号]` | 查看当前或指定群授权状态 |
| `使用卡密…` | 消耗卡密为本会话开通授权 |
| `生成天卡授权[n]` / `生成周卡授权[n]` / `生成月卡授权[n]` / `生成半年卡授权[n]` / `生成年卡授权[n]` / `生成永久卡授权[n]` | 主人批量生成卡密 |
| `添加…授权` | 直接为指定对象添加对应时长授权 |
| `卡密列表` | 查看未使用 / 已生成卡密 |
| `删除卡密` / `清空卡密` | 删除或清空卡密库存 |
| `删除授权` / `取消授权` | 撤销授权 |

时长档位：**天 / 周 / 月 / 半年 / 年 / 永久**（秒数在代码内建表）。

发送 `MK介绍` 可查看带真实回复示例的授权演示对话。

群事件配置：`筱筱吖/事件系统/{群号}.json`  
全局事件配置：`筱筱吖/事件系统/全局.json`

### 开关方式

```text
开启入群欢迎
关闭违禁检测
开启全部事件
关闭全部事件
```

也可用 WebUI「开关管理」按群批量操作。  
**全局事件**仅主人可开关。  
**智能对话**自 2.3.7 起不再走事件列表，改为独立开关（见 [智能对话](#智能对话ai)）。

## 群管系统

入口指令：`群管系统` / `群管功能` / `群管菜单`

### 禁言 / 踢人 / 管理

| 指令族 | 示例 |
|--------|------|
| 禁言 / 解禁 | `禁言`、`解禁`、`时禁言`、`天禁言`、`周禁言`、`月禁言` |
| 管理位 | `上管`、`下管` |
| 踢人 | `踢出`、`黑踢` |
| 全体 | `全体禁言`、`全体解禁`、`全解群员` |
| 列表 | `获取禁言列表` |

### 群资料与公告

- `更改群名称` / `更改群名字` / `更改群头像`
- `发公告`
- 跨群群发：`获取可群发…`、`新增可群发…`、`取消可群发…`、`☆执行群发公告` / `☆执行群发文本`（具体以菜单为准）

### 入群审核 / 验证 / 私聊

- **审核条件**：准确、包含、模糊多重、准确多重、字数等；可配答案、过滤器、日限额
- **入群验证**：次数 / 时长 / 模式；`取消入群验证`
- **入群私聊**：`开始记录`、`结束记录`、`查看记录内容`、`设置入群私聊概率`

### 头衔与马甲

- `我要头衔`、`设置头衔`、`全员头衔` / `全体头衔`
- `设置马甲内容`、`全员马甲`

### 黑名单与「骨灰」成员

- 本群 / 全局：添加、移除、清空；`查黑名单`
- 处理方式：踢出 / 黑踢
- 不活跃成员：列表、提醒、取消、清理；标准支持七日 / 半月 / 一月或自定义天数

### 违禁与发言限制

- 违禁词库；可禁发图片 / 视频 / 语音 / 卡片 / 合并转发
- `设置违禁处理…`
- 发言字数 / 行数 / 艾特限制
- 排行：今日 / 昨日 / 七日 / 本月 / 个人

### 欢迎 / 退群 / 邀人

- 入群欢迎、退群通知文案模板
- `邀人统计`、`查看我的邀请`、`查看他的邀请`、`邀人排行榜`、`操作邀请官…`

### 其它

- `清屏`、`查群员…`
- `获取群文件列表`（需开启「测试功能」）
- `拍我`、`赞我`

> 多数管理向指令在「管理模式」开启后，群主 / 管理也可执行；敏感操作仍受主人校验（如 `checkOwner3`）。

## 发卡系统

与「授权卡密」不同：用户花费 **归笺** 兑换货架商品，机器人将库存中的卡密 / 兑换码 **私聊投递**。

模块：`src/auth/card-shop*.ts`  
WebUI：扩展功能 → 发卡系统（`/mkbot/card-shop/*`）

| 角色 | 指令 / 能力 |
|------|-------------|
| 用户 | `发卡系统` / `发卡商店` / `查看商品列表` / `兑换商品 名 数量` |

## 智能对话（AI）

模块族：`src/auth/smart-chat*.ts`  
开关目录：`筱筱吖/扩展功能/智能对话/`  
**独立于事件系统**（2.3.7+）：后台折叠栏「智能对话」→「配置聊天」「聊天开关」。

### 能力摘要

- 厂商：**深度求索**、**幻城（hcnsec）**、**英伟达 NIM**（OpenAI 兼容）
- 群聊 / 好友分栏开关；点头像可开 **仅 AI 对话**（本对象跑完 AI 后截断后续群管 / 娱乐，定时任务不受影响）
- 群指令：`开启智能对话` / `关闭智能对话`（兼容旧事件已开状态）
- 可配：API Key、模型、temperature、max_tokens、防抖、批处理、System Prompt、禁言阈值、动作随机区间、联网搜索（Tavily / Serper / Bocha）、识图队列等
- 知识库：开启条目全量注入（不再 Top-M 截断）；更新内容不影响历史会话命名空间
- 输出标签：`<replies>`、`<msg>`、`<react>`、`<shut_up/>` 等
- 默认人设偏软萌可斗嘴、不暴露 AI 身份；强化禁 Markdown；失败 / 超时只写日志、不往群甩报错

触发点在消息记录之后，便于「仅 AI」仍可入档再截断。

## 从源码构建

### 依赖

- Node.js（建议较新的 LTS）
- npm 或 pnpm（仓库含 `package-lock.json` 与 `pnpm-lock.yaml`）
- 网络可访问 npm registry（`sharp` 原生包较大，慢网请加长超时或换镜像）

### 一键脚本

- Windows：`install-build.bat`（`npm install` + `npm run build`，并拉长 fetch-timeout）
- Unix：`install-build.sh`

镜像示例：

```bash
npm config set registry https://registry.npmmirror.com
```

### 手动命令

```bash
npm install
npm run build      # sync VERSION → vite 打包 → build-api
npm run watch      # 开发监听
npm run typecheck  # tsc --noEmit
```

构建流程：

1. `scripts/sync-version.mjs` — 从 `VERSION` 同步版本到 `package.json` / `plugin.json`
2. Vite 6 lib 模式 — 入口 `src/index.ts` → `napcat-plugin-mkbot/index.mjs`
3. `scripts/build-api.mjs` — 打包视频 / 图床等 API 到 `lib/api/*.mjs`

产物目录 `napcat-plugin-mkbot/` 通常包含：`index.mjs`、`plugin.json`、`package.json`、`webui/`、`data/`、`assets/`、`lib/api/`。

运行时外部依赖：`sharp`（不内联进 bundle）。

## 常见问题

**Q: 装了没反应？**  
检查 `OwnerQQs`、会话是否在 `group_of` / `haoyou_of`、是否授权或已「绕过授权」、宿主是否真正加载了本插件。

**Q: 卡片不渲染 / 一直纯文本？**  
确认 `图片渲染` / `渲染开关`；`渲染模式` 为 `html` 时需 Puppeteer 插件可用；`sharp` 模式需原生模块安装成功（WebUI → Sharp 依赖安装）。

**Q: NapCat 4.18.5+ 异常？**  
官方建议改用 **Kakake** 框架加载本插件。

**Q: sharp 安装失败 / 超时？**  
拉长 `fetch-timeout`，或设置 npmmirror；Windows 注意下载 `@img/sharp-win32-x64` 等平台包。

**Q: 娱乐指令无效？**  
查 WebUI 娱乐分项开关，或旧总开关「深度娱乐」；确认群已授权。

**Q: 全群群老婆很卡？**  
超大号 / 超大群慎开，菜单内亦有相关提示。

**Q: 漂流瓶隐私？**  
设计上无隐私保障，主人侧可见，请勿用于敏感内容。

**Q: 双包名搞混？**  
NapCat 侧多为 `napcat-plugin-mkbot`，Kakake 侧为 `kakake-plugin-mkbot`，数据目录务必与宿主一致。

**Q: 第三方接口挂了？**  
音乐、图片、视频、运势、Epic、PearAPI 等均依赖外网；可用性与 ToS 不在本仓库控制范围内。
